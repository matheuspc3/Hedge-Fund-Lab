# Documentação do Hedge-Fund-Lab

Este índice separa estado, arquitetura, planejamento, protocolo científico e
material histórico.

- [`ROADMAP.md`](ROADMAP.md) — única fonte de verdade para planejamento,
  prioridades, progresso e próximas fases.
- [`ESTADO_ATUAL.md`](ESTADO_ATUAL.md) — fotografia verificável do que existe
  hoje, com limitações conhecidas.
- [`ARQUITETURA.md`](ARQUITETURA.md) — organização técnica atual e arquitetura
  alvo.
- [`EXPERIMENT_PROTOCOL.md`](EXPERIMENT_PROTOCOL.md) — contrato científico do
  experimento; permanece draft até aprovação e congelamento.
- [`faculdade/`](faculdade/) — materiais acadêmicos, incluindo a monografia.
- [`archive/`](archive/) — planos e handoffs históricos que não orientam o estado
  atual nem o planejamento ativo.

Resultados mock ou demonstrações técnicas não constituem evidência científica.
